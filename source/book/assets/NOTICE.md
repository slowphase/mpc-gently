# Third-party artwork

Some files in this folder are Akai Professional / inMusic artwork:

- `akai.svg`, `akai_cream.svg`, `akai_ink.svg`, `akai_mask.png`: the Akai Professional logo, traced from Akai's official logo artwork.
- `mpcsample.svg`, `mpcsample_cream.svg`, `mpcsample_orange.svg`, `mpcsample_mask.png`, `userguide_mask.png`: MPC Sample and User Guide lettering, traced from the same artwork.
- `overview.png`: the labelled top-panel diagram from the official *MPC Sample User Guide*.
